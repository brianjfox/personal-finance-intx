# Corbits Personal Finance 0.4.0

Tax lots become something you can see and manage: view every position's
lots, enter what the institutions don't know, and let Kraken's ledger
fill in what it does.

## What changed

- **See a position's tax lots.** On the Positions tables, the cost-basis
  cell opens the position's lot list — acquisition date, quantity,
  basis — oldest first, scrolling when there are hundreds. Bases you
  typed in are badged "entered by you".
- **Enter a basis where it's unknown.** Unknown lots offer "Enter
  basis", prefilled with the lot's value on the day it arrived (recorded
  from Coinbase's own transaction record where possible) and showing
  the market unit price looked up for the acquisition date. You can
  also correct the acquisition date — arrival is not purchase. Entries
  are journaled, survive every update (scaled if the lot is partly
  sold), and give the Auditor a real long/short-term call instead of a
  "basis unknown" caveat.
- **Add lots by hand.** Institutions that report no lot data (watch-only
  wallets, exchanges with restricted keys) show an honest message and an
  "Add a lot" form. A position's lots can never sum past what it holds,
  and its own cost basis fills in only when the lots cover the whole
  position.
- **Kraken tax lots.** With a Kraken API key that has "Query ledger
  entries", each update walks the account ledger into lots: fiat-quoted
  trades carry their real basis (fees included), crypto-to-crypto
  trades and staking rewards get their true dates, deposits arrive as
  "basis unknown" transfers, and everything reconciles exactly against
  the balance or the lots are withheld. Without the permission, nothing
  breaks — you can still add lots by hand.
- **Table manners.** Long hash-suffixed account ids ellipsize in the
  middle (the full id stays in the tooltip), so one Plaid-style id no
  longer stretches the whole table.
