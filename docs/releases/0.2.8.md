# Corbits Personal Finance 0.2.8

A Market Manager decline is now an answer you can read, and a stale
error from an older install no longer masquerades as this run's reason.

## What changed

- **When the Market Manager declines, it says why.** It may answer
  `NOTHING` followed by one sentence, and that sentence reaches the
  journal and the Strategy page: "No proposal this time — the Market
  Manager reviewed the drift and declined to propose: …". Before, the
  bare word was required, so there was nothing to show.
- **A decline ends the run after one attempt.** The same drift report
  can only draw the same answer, so the redraft loop no longer asks
  twice more and then reports an "exhausted" loop. The run ends at a
  journaled *declined* outcome with the approval gate never armed;
  "exhausted" now means exactly what it says — every redraft was
  blocked by the Auditor — and names the last verdict.
- **No more ghost failures.** Installs that ran a proposal before 0.2.7
  keep an old flat child-run log on disk; its dead "missing key intake
  in path steps.intake.output" was being reported as the reason for
  every later, perfectly clean run. The legacy log is now consulted
  only for runs that actually predate 0.2.7.

## Tip

If the Market Manager declines because the only candidate is one huge
order, set **Max order value** in the plan editor — the drift engine
otherwise sizes a single order to the full excess.
