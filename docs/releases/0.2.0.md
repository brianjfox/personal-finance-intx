# Corbits Personal Finance 0.2.0

The release that runs on more machines. Everything below landed since
0.1.1.

## One Mac app for both architectures

- The macOS download is now a **universal** app: Apple silicon and
  Intel Macs (macOS 13+) get the same dmg, and the embedded `fin-host`
  is a fat binary too.

## Windows, first build

- **Corbits Personal Finance runs on Windows 10/11 x64** — the same GUI
  and the same host, installed by a standard setup wizard (WebView2 is
  fetched only on machines that lack it).
- **Secrets go to Windows Credential Manager** (`fin-*` generic
  credentials, visible in the control panel), with a DPAPI-protected
  file as the fallback where PowerShell's compiler is unavailable.
  Delete-all-data sweeps them the same way it sweeps the macOS Keychain.
- **Truthful at-rest copy**: the login screen reports what actually
  protects your data directory — a per-user encrypted volume (macOS),
  the OS disk encryption (BitLocker/Device Encryption on Windows), or
  nothing, with a plain warning in the last case. Security copy is
  worded for the platform you are on.
- Data lives in `%APPDATA%\CorbitsPersonalFinance`; Ledger Live import
  reads its Windows path; links open through the shell's URL handler.
- Caveats, stated up front: the installer is **unsigned** (SmartScreen
  will warn: More info → Run anyway), x64 only (ARM64 runs under
  emulation), and this build has not yet had its full VM smoke pass —
  treat it as a preview and report what you find.

## Everywhere

- Below tablet width the closed navigation drawer no longer leaks a
  shadow down the left edge of the screen, and it can't be tabbed into
  while hidden.

## Under the hood

- Continuous integration runs the whole suite on macOS and Windows.
- Releases are cut by `scripts/release.sh`, built by CI, and published
  from a reviewed draft (docs/RELEASING.md) with SHA-256 sums alongside
  every download.
