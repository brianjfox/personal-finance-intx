# Corbits Personal Finance 0.2.2

A build-pipeline release: the same app as 0.2.1, now signed and
notarized by the release workflow itself.

## What changed

- The macOS download is Developer ID signed and notarized straight from
  CI — the stapled app goes into the dmg before it is packed, so it
  installs on a Mac that has never been online.
- No functional changes to the app since 0.2.1 (the Ascent icon and
  everything before it carry forward).
