# Corbits Personal Finance 0.2.1

The icon release. Everything below landed since 0.2.0.

## A mark that says finance

- The app icon and the in-app mark now carry the **Ascent** design: the
  Corbits mountain over four ascending bars, with a trend arrow rising
  through them toward the summit. No currency symbol — the app is
  multi-currency. It reads at Dock, Finder, title-bar, and menu-bar
  sizes; the sources ship in the repo as SVG.

## Downloads, trimmed

- The release attaches only what you need to install: the macOS dmg
  (one universal app for Apple silicon and Intel), the Windows
  installer, and a checksum file to verify them. The `fin-host`
  command-line engine is inside both bundles and is no longer a
  separate download.

## Carried forward

- Everything from 0.2.0: the universal macOS app, the first Windows
  build (unsigned — SmartScreen will warn; treat it as a preview), and
  the reviewed-draft release process.
