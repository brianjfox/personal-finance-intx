# Corbits Personal Finance 0.7.1

**The first update that arrives on its own.** 0.7.0 carried the
updater; this is the first release it can install. Check for Updates…
in the application menu finds it, and Update installs it and relaunches.

**An address watched twice is caught, and refused.** A watch-only
wallet address that another entry already watches is now refused by
name when you add it, and the same address twice in one list is refused
too. Every night the reconciler looks across all open wallet accounts,
regardless of which entry they belong to, and raises a break for any
address two of them share, naming both accounts and the remedy: remove
all but one of those entries on Credentials. The finding clears itself
once one of the accounts is closed. A device imported from Ledger Live
on top of addresses added by hand had counted the same coins twice in
net worth since August, and nothing had said so.

**The host stops when told.** Quitting or reinstalling the app used to
leave the previous host running in the background, deaf to a stop
signal. It now stops within seconds of a signal and follows the app out
on its own when the app is gone, so one household never has two hosts
running against the same ledger.

**Smaller things.** The Dashboard's account table column that read
"balance.total" now says where a value came from, in words: stated
balance, positions, or amount owed.

Everything else is 0.7.0.
