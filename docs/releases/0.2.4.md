# Corbits Personal Finance 0.2.4

Two first-run fixes, both found on a fresh Windows install.

## What changed

- **The Enable Banking private key now saves on Windows.** Windows caps
  a Credential Manager entry at 2560 bytes, so saving the RSA private
  key (a ~3 KB PEM) failed with "CredWrite failed: 1783". Larger
  secrets are now stored transparently across several Credential
  Manager entries and reassembled on read; nothing changes for secrets
  that already fit, and macOS is unaffected.
- **Settings opens before any data exists.** On a brand-new install the
  welcome screen used to swallow the Settings page (on every platform).
  Settings is just display preferences, so it now renders whether or
  not anything is connected yet.
