# Corbits Personal Finance 0.4.1

Everything in 0.4.0, plus a desktop app that stays alive for the
nightly imports — with a menu-bar icon, an instant window, and a real
splash screen.

## What changed

- **Closing the window no longer stops the host.** The app now lives in
  the menu bar: close the window and the household host keeps running —
  so the nightly imports, reconciliation, and deadline checks actually
  happen. The menu-bar icon offers *Open* and *Quit*; only Quit (from
  the tray or the application menu, ⌘Q) stops the host. The Dock icon
  and the tray both re-open the window.
- **Launching feels alive.** The window opens instantly on a splash —
  the Corbits mark, a spinner, "Starting the household host…" — and
  switches to your dashboard the moment the host answers, however long
  the first boot takes. (Before, a double-click could show nothing, or
  a blank window, for up to a minute.)
- The menu-bar icon is a proper monochrome template image, tinted by
  macOS for light and dark menu bars.

## From 0.4.0 (unpublished)

- **Tax lots throughout**: view every position's lots from the
  cost-basis cell (scrolling lists, oldest first); enter a basis where
  it's unknown — prefilled with the lot's value on its transfer date
  and the market unit price looked up for that day — or add lots by
  hand for institutions that report none; entries are badged, journaled,
  and survive every update.
- **Kraken tax lots** derived from the account ledger (with the "Query
  ledger entries" key permission), reconciled exactly against balances.
- Long account ids ellipsize instead of stretching tables.

## After upgrading

Install the new app, launch it once, and let it live in the menu bar.
Run an update on Coinbase and Kraken to populate the lots.
