# Corbits Personal Finance 0.1.1

The release that renamed the product. Everything below landed since the
0.1.0 baseline.

## The Corbits console

- **New identity**: the product is Corbits Personal Finance, wearing the
  orange mountain mark — app icon, title bar, and About popup (click the
  logo or the name; the version there is stamped from the same field
  that versions this bundle).
- **Redesigned throughout** from the six Corbits Finance screens:
  Dashboard, Attention Queue, Assets, People, Tax Calendar timeline, and
  the Strategy chat workspace — dark console styling, all data live, and
  no CDN dependencies (the packaged app renders identically offline).
- **Settings**: theme (Light / Dark / **Auto** — the new default,
  following the macOS appearance), font size, and background/foreground
  colors stored per theme. The default dark theme is neutral charcoal.
- **The privacy eye** beside the title-bar net worth veils every
  financial figure with *s until clicked again; the choice persists.
- **Phone-ready**: below tablet width the sidebar becomes a slide-in
  menu, layouts go single-column, tables and charts scroll inside their
  panels, and an over-long KPI row steps its font down uniformly.

## Cash flow

- Connectors already fetched a rolling 30-day transaction window each
  nightly; a **fresh connection now backfills a full year** so the
  picture is real from day one (Enable Banking falls back gracefully
  where a bank caps history).
- The dashboard's **Cash Flow panel** charts monthly money in/out from
  observed transactions — transfers between your own accounts and
  in-account buys/sells excluded — and the Flow Summary reports net
  inflow, average monthly spend, and runway at average burn.

## Operations

- **View Fetch Logs** on each connected institution: the raw HTTP
  request/response record of recent fetches, headers included,
  credentials masked before storage, held in memory only.
- **Make available on my LAN** (Settings → Network, or `serve --lan`):
  password-gated, Host-header allowlisted, plain about being plain
  HTTP; the panel names the exact address to open from a phone.
- The tax-year standing run, approvals, and every earlier capability
  carry forward unchanged.
