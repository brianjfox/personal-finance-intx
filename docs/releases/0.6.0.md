# Corbits Personal Finance 0.6.0

**The standard menu bar.** The app now carries the menus a Mac app is
expected to have. The application menu holds About, Settings (⌘,),
Check for Updates, the Kill Switch, and Services, Hide, Hide Others,
Show All, and Quit. File has New Window, Close Window (⌘W — the host
keeps running, as before), and Print. Edit gains Undo and Redo. View
has Enter Full Screen. The Window menu has Minimize, Zoom, Bring All to
Front, and the window list. Help has the app's own help — every
Tricks & Tips line in one place — plus Release Notes and Report an
Issue. Check for Updates asks GitHub for the newest published release
and tells you whether you have it, with a link; nothing downloads or
installs itself.

**Every figure in the queue follows your currency.** The before/after
fact cards on the Attention Queue showed raw numbers with no currency;
they now format like the rest of the app, converted into your preferred
currency at ECB rates, and the privacy veil hides them. The sentence on
each card does too: a mismatch reads "positions sum to €6,000.00 but the
institution states €6,250.00" under a euro preference, because findings
now carry their money figures as data rather than as words. Findings
written before this release keep their original wording.

Everything else is 0.5.0, including the Ledger Analyst.
