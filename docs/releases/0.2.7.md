# Corbits Personal Finance 0.2.7

The Market Manager gets a home, a plan you can write in the app, and
plain-words answers when a proposal run ends — plus one page-header
pattern across the whole app.

## What changed

- **Strategy now has two tabs.** *The Strategist* is the chat you
  already know (advises and journals, never drafts trades). *Plan &
  Rebalancing* is the Market Manager's home: your written plan's targets
  with live actual/drift columns, out-of-band asset classes highlighted,
  the propose button, proposals awaiting your signature, and prepared
  orders. Queue goes back to holding only reconciliation exceptions;
  the bell in the top bar counts both and opens whichever needs you.
- **Write the investment plan in the app.** Plan & Rebalancing carries
  a plan editor — target weights per asset class with a live total that
  flags anything short of 100%, the drift band, never-sell symbols, max
  position weight, max order value, and notes. The propose button stays
  disabled (and says why) until a plan exists; an existing plan opens
  the same editor behind "Edit the plan". Errors show inline on the
  page, never as a popup naming a file path.
- **Every proposal run now says how it ended.** "Ask the Market Manager
  for a proposal" could return in a blink with nothing on screen. The
  page now reports the outcome in plain words: no asset class is
  outside its band (journaled, no model call, no empty approval), the
  Market Manager declined, the redraft loop ran out, or the deepest
  failure inside the run. A model answering "NOTHING" is understood as
  an answer rather than a crash, and gpt-oss "harmony" scaffolding in
  a draft is stripped before the Auditor reads it.
- **Proposals no longer replay the first failure forever.** Every
  click after one failed run returned the identical failure in
  milliseconds because all proposals shared one on-disk child-run slot.
  Child runs are now filed under their parent, and a run that settled
  is reported as settled rather than "queued".
- **One header, one tab pattern, same position everywhere.** Tabbed
  pages (Assets, Strategy, Audit Logs, Documents) share a single header
  structure — title with page actions, a one-line description, then a
  segmented tab row — and the chat tab sits at exactly the same pixels
  as every other page (no more jump when switching Strategy tabs).
- **Drag-to-reorder actually drops.** Dragging an institution card
  snapped back on macOS because the window's file-drop handler swallowed
  in-page drags; that handler is off, and the grip is a wider strip
  along the card's left edge.
- **Assets rail tidy-ups.** The Setup Progress card reads "Completion"
  and retires itself at 100%. "Expert Mode" is now "Tricks & Tips": 22
  rotating one-sentence tips about real behaviors of the app, legible in
  both themes. The break-glass export caption says what the button does.
